### 1.1 `skill` 的字段取值约定

| 字段 | 取值 | 说明 |
| --- | --- | --- |
| `skill_id` | `lib:<slug>` / `<host>:<owner>/<repo>/<name>` / `local:<contributor>/<name>` | 唯一键 |
| `slug` | 归一化的 `name`（小写、非字母数字转 `-`，允许中文） | 库目录名 |
| `source` | `library` / `github` / `gitee` / `gitlab` / `gitcode` / `upload` | 分发来源 |
| `author_kind` | `personal` / `department` | 贡献者类型 |
| `risk_level` | `safe` / `low` / `medium` / `high` / `unrated` | 与分数区间一一对应 |
| `status` | `published` / `archived`（本版不产生 draft/submitted） | 归档 = 软删 |
| `skillset_code` | 恒为 `default` | 为与标准版共用 DDL 而保留，本版不暴露 |

## 3. 错误码（本版本实际会返回的 14 个）

| code | 常量 | HTTP | 触发场景 |
| ---: | --- | ---: | --- |
| 0 | OK | 200 | 成功 |
| 1000 | INVALID_PARAM | 400 | 参数不合法（含上传超限、JSON 解析失败、方法不支持=405） |
| 1001 | MISSING_PARAM | 400 | 缺少必填参数 |
| 1100 | NOT_FOUND | 404 | 文档 / 贡献记录 / 版本不存在 |
| 1101 | SKILL_NOT_FOUND | 404 | skill_id 不存在（含已删除） |
| 1201 | VERSION_EXISTS | 409 | 发布或编辑时版本号重复 |
| 1300 | STATE_ILLEGAL | 409 | 未签 CLA 就提交/发布；已驳回后发布 |
| 1400 | ROLE_FORBIDDEN | 403 | viewer 编辑；非 admin 物理删除 |
| 5000 | INTERNAL_ERROR | 500 | 未捕获异常（带 trace_id） |
| 5001 | DB_ERROR | 500 | SQL 失败（只回第一行原因） |

（2000/2003/2100 属标准版；300x 属标准版/专业版的接入；4000/6000 本版不产生。）

## 4. 版本与兼容

- 只有 `/api/v1`，本版不引入 v2。
- 新增字段一律追加；前端必须容忍未知字段。
- 三系统同名端点的响应字段集合必须一致（PSKH 可多不可少），由 `tools/verify-all.mjs` 校验。

## 5. 数据初始化与重灌

```powershell
# H2：删数据目录即清库
Remove-Item data\db -Recurse -Force ; .\start.cmd

# MySQL：删库重建
mysql -h 127.0.0.1 -P 3306 -u root -e "DROP DATABASE eskh; CREATE DATABASE eskh DEFAULT CHARACTER SET utf8mb4;"
$env:SKHUB_DB='mysql'; .\start.cmd
```

导入是**幂等**的：`skill` 表非空则跳过。要强制重新导入，清库即可。
