## 7. 已知限制（与 README 一致，此处附验证方式）

| 限制 | 怎么验证 | 影响 |
| --- | --- | --- |
| 不做登录 | 把 `X-SKH-Role` 改成 admin 即可物理删除 | 不能当权限控制用 |
| 检索是关键词加权 | 搜"合同审查"不会命中"协议审阅" | 同义词检索缺失 |
| 评估是静态规则 | 用在线试算贴一段自然语言攻击，分数可能不高 | 语义级漏检 |
| 无版本 diff | 版本卡只有快照，没有逐行对比 | 升级前需人工比对 |
| 无速率限制 | 循环 GET `/download` 不会被拦 | 建议网关层限流 |
| 贡献无审核队列 | 同一人可完成 4 步 | 内网工具场景的取舍 |
